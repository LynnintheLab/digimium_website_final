DEMO-001

Spotify Individual · ၁ လ

ဆိုင်အတည်ပြုရန် စောင့်နေသည်

ဆိုင်က အတည်ပြုပြီးရင် သက်တမ်းရက်စွဲကို ဒီမှာ ပြပေးပါမယ်။

16,000 ကျပ်

အကောင့်မသုံးဘဲ ဝယ်ထားရင် Telegram က အော်ဒါစာမှာ ပြန်ကြည့်ပါ။

၁။ အောက်ခြေမှာ အရေးကြီးလမ်းတွေကို ထားပါ

  1. ရွေးချယ်ထားသော floating dock — ပစ္စည်းများ၊ မှတ်တမ်း၊ အကောင့်နဲ့ အကူအညီကို အမြဲရှာတွေ့နိုင်စေပါ။
  2. အလယ်က အကောင့်ခလုတ်ကို သိသာစေပါ — ပြန်လာသူများအတွက် အကောင့်ကို အဓိကလမ်းအဖြစ် အပြာရောင်၊ မြှင့်ထားသော User icon နဲ့ ပြထားသည်။ ဤနမူနာတွင် အတည်ပြုထားသော အကောင့်ဝင်ပုံစံကို ဖွင့်သည်။
  3. ဈေးခြင်းကို ဘေးမှာ အရေအတွက်နဲ့ ထားပါ — ဈေးခြင်းကို နှိပ်ရင် review ကိုပဲ ဖွင့်သည်။ အော်ဒါ အလိုအလျောက်မတင်ပါ။ Icon နဲ့ စာသားကို တွဲထားပြီး catalog ကို scroll လုပ်ရာမှာ အောက်ဆုံးအကြောင်းအရာကို dock မဖုံးစေရန် နေရာချန်ထားသည်။
  4. ပေးချေနိုင်သည့်နည်းကို သိစေပါ — ဆိုင်ရှင်အတည်ပြုထားသော KBZ / Wave / AYA / uabpay / Binance ကို မူရင်း logo များနဲ့ ပြထားသည်။ ငွေပေးချေမှုက Telegram မှာ ဖြစ်သည်။

အသုံးပြုသူရွေးထားသော navigation ပုံစံဖြစ်သည်။ လူကြီးပိုင်းအသုံးပြုသူများနှင့် လက်တွေ့စမ်းသပ်ပြီး တုံ့ပြန်ချက်ယူရန် ကျန်သည်။

၂။ ရိုးရှင်းသည့် ဝယ်ယူမည် ခလုတ်

  1. ဝယ်ယူမည် — အသုံးပြုသူရွေးချယ်ထားသော မြန်မာစာ action ဖြစ်သည်။ နှိပ်ပြီးနောက် အော်ဒါ၊ အရေအတွက်နဲ့ စုစုပေါင်းကို ပြန်စစ်နိုင်သည်။
  2. ရွေးထားသည့်အစီအစဉ် ထင်ရှား — သက်တမ်း၊ ဈေးနှုန်းနဲ့ radio ရွေးချယ်မှုကို တွဲပြထားသည်။
  3. အလိုအလျောက် အော်ဒါမတင် — ဤခလုတ်မှ နောက်မျက်နှာပြင်ကို သွားခြင်းသာ ဖြစ်သည်။ Checkout ထဲမှာ floating dock မထည့်ထားပါ။

၃။ အော်ဒါကို တစ်ချက်ကြည့်ပြီး နားလည်ပါစေ

  1. တစ်နေရာတည်းမှာ တိုတိုပြ — Service၊ သက်တမ်း၊ အရေအတွက်၊ စုစုပေါင်းနဲ့ payment logo အသေးများကို စုထားသည်။ စာပိုဒ်ရှည်များကို ဖယ်ထားသည်။
  2. နှစ်နည်းလုံး Telegram — အကောင့်နဲ့ ဝယ်ခြင်းက website မှတ်တမ်းနဲ့ သက်တမ်းကို ပြန်ကြည့်နိုင်ခြင်း ဖြစ်ကြောင်း ခလုတ်အောက်မှာ ရှင်းပြထားသည်။
  3. Guest ကို ရွေးမီ ကန့်သတ်ချက် သိစေ — website မှတ်တမ်းမရခြင်းနဲ့ Telegram စာကို သိမ်းထားရန် အတိုချုံးပြထားသည်။ Login ပြီးလည်း ဒီ review ကို ပြန်လာသည်။

၄။ ဝင်လို့ရသည့်နည်းတွေ ရှေ့တင်ပါ

  1. Google / Telegram ခလုတ်တွေ အလုပ်လုပ် — ဒီနေရာမှာ ဒေသတွင်းနမူနာ sign-in သာဖြစ်ပြီး တကယ့် provider ကို မဖွင့်ပါ။
  2. Phone မရသေးခြင်း ရှင်း — လုပ်လို့ရသလိုမြင်ရသည့် disabled ခလုတ်ကြီး မလုပ်ပါ။Finding: unavailable provider prominence
  3. စကားဝှက် ဖတ်စစ်နိုင် — Email ဖြင့် ဆက်မယ်ကို နှိပ်ပြီး ပြ/ဝှက် နမူနာ စမ်းပါ။Finding: password visibility / assistance
  4. Recovery မရှိသေး — အကူအညီခလုတ်သည် ပုံစံအဆိုပြုချက်သာဖြစ်သည်။ Password reset backend ရှိပြီးသားဟု မဖော်ပြပါ။ Google–Telegram account linking လည်း ဤအဆိုပြုချက်တွင် မပါပါ။

၅။ သိမ်းပြီး Telegram ဖွင့်၊ website ကလည်း ပြန်ဆက်နိုင်ပါစေ

  1. အော်ဒါသိမ်း → Telegram အလိုအလျောက်ဖွင့် — ဤမျက်နှာပြင်သည် အပိုမဖြစ်မနေဖြတ်ရမည့် အဆင့် မဟုတ်ပါ။ Website မှာ အတည်ပြုစာကို ချန်ထားပြီး Telegram ကို ဆက်ဖွင့်မည့် ပုံစံဖြစ်သည်။
  2. တင်ပြီးသည်ဆိုတာ paid/approved မဟုတ် — ဆိုင်အတည်ပြုရန် စောင့်နေကြောင်း ရှင်းစေသည်။ Telegram မှာ Send နှိပ်ရသေးကြောင်းကိုလည်း ပြထားသည်။
  3. ဖွင့်မရရင် ပြန်ဖွင့် / ကူးယူ / အကူအညီ — နမူနာအော်ဒါကို ဒီ browser ထဲမှာသာ သိမ်းထားပြီး reload လုပ်လည်း ဆက်ကြည့်နိုင်သည်။ အစစ်မှာလည်း ထို fallback ကို ဆက်ပေးရန် အဆိုပြုထားသည်။

Prototype သာဖြစ်သည်။ Telegram အစစ်၊ network၊ clipboard၊ payment သို့မဟုတ် message API မသုံးပါ။

၆။ ကျန်ရက်ကို အရင်မြင်စေပါ

  1. ၂၃ ရက်ကျန် — နံပါတ်ကြီးနဲ့ ဖော်ပြ — Circular meter သည် နမူနာသက်တမ်း ရက် ၃၀ အနက် ကျန်သည့် ၂၃ ရက်၊ ၇၆.၆၇% ကို ပြထားသည်။ အလှအပအတွက် သတ်မှတ်ထားသော ရာခိုင်နှုန်း မဟုတ်ပါ။
  2. ရက်စွဲနဲ့ စာသားကို တွဲပြ — စတင်ရက်၊ ကုန်ရက်နဲ့ အသုံးပြုနိုင်ဆဲ စာသားကို ပြထားသည်။ Screen reader အတွက် meter value/text ပါသည်။
  3. စောင့်ဆိုင်းဆဲ / ဝယ်ယူပြီး တစ်နေရာတည်း — Account settings ထဲ သွားရှာရသည့်အဆင့် လျှော့ပြီး မှတ်တမ်းကို မပျောက်သလို ခံစားရစေသည်။

Google–Telegram account linking သည် နောက်မှလုပ်ရန် သီးခြားသိမ်းထားသော feature ဖြစ်သည်။ ဤနမူနာမှာ ချိတ်ဆက်ပြီးဟု မဖော်ပြပါ။

ရွေးချယ်ထားသော ပုံစံ၏ အဓိကအချက်များ

  1. Label ပါသော floating dock၊ အလယ်က အကောင့် action၊ ဘေးက ဈေးခြင်းမှာ အရေအတွက် badge။
  2. “ဝယ်ယူမည်” နှိပ်ပြီး အော်ဒါကို ပြန်စစ်ခွင့်။
  3. တိုတောင်းသည့် review၊ payment logo အသေးများ၊ account/guest မှတ်တမ်းကွာခြားချက်။
  4. အတည်ပြုထားသော login ပုံစံကို ဆက်ထားခြင်း။
  5. အော်ဒါသိမ်းပြီး Telegram အလိုအလျောက်ဖွင့်၊ ပြန်လာလည်း website confirmation ရှိခြင်း။
  6. စောင့်ဆိုင်းဆဲ / ဝယ်ယူပြီး အတူထားပြီး ကျန်ရက်ကို circular meter နဲ့ ပြခြင်း။
