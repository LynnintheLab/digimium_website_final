# Digimium UX report — အတိုချုပ်

**15 November 2026 · Wireframe ကိုသာ ပြင်ထားပါတယ်။ Website မပြင်သေးပါ။**

ပစ္စည်းရှာခြင်း၊ plan ရွေးခြင်း၊ ဈေးခြင်း၊ account နှင့် history ကို browser မှာ စမ်းထားပါတယ်။ ဖုန်းအရွယ် 320/390px နဲ့ 200% zoom ကိုပါ စစ်ထားပါတယ်။ **လူကြီးပိုင်းအသုံးပြုသူတွေနဲ့ တိုက်ရိုက်မစမ်းရသေးပါ။** အော်ဒါအသစ်၊ ငွေပေးချေမှုနဲ့ password ပြောင်းခြင်း မလုပ်ထားပါ။

## အဓိက ပြင်ဖို့လိုတာ ၄ ခု

1. **ဝယ်ယူနည်း မရှင်းသေးခြင်း။** Account/guest နှစ်မျိုးလုံး Telegram မှာ ဆက်လုပ်ရပေမယ့် ခလုတ်စာသားက ကွာခြားသလို ထင်ရနိုင်ပါတယ်။ Website history ရ/မရကို ရွေးချယ်စဉ်မှာ ရှင်းပြရန်လိုပါတယ်။
2. **ဖုန်းမှာ ဖတ်ရ၊ ရှာရ ခက်ခြင်း။** English ဝယ်ယူခလုတ်တွေ၊ စာသေးတာနဲ့ Account/Cart ကို icon ပဲပြထားတာကို ပြင်ရန်လိုပါတယ်။
3. **Password အကူအညီမရှိခြင်း။** Source မှာ forgotten-password recovery နဲ့ ပြ/ဖျောက် control မတွေ့ပါ။ တကယ့် password မှားရိုက်စမ်းခြင်း မလုပ်ထားပါ။
4. **မှတ်တမ်းရှာရ ခက်ခြင်း။** Pending ကို Account မှာ၊ approved ကို History မှာ ခွဲပြထားပါတယ်။ တစ်နေရာတည်းမှာ အခြေအနေရွေးကြည့်နိုင်သင့်ပါတယ်။

## ရွေးထားသော wireframe ပြင်ဆင်ပုံစံ

- **Menu A:** floating အောက်ခြေ menu ကို **ပစ္စည်းများ · ဈေးခြင်း · အကောင့် · မှတ်တမ်း · အကူအညီ** ဟု ထားမည်။ အလယ်မှာ **အကောင့်** ကို အလေးပေးပြီး ဈေးခြင်းမှာ အရေအတွက် badge ပြမည်။
- အဓိက action ကို **“ဝယ်ယူမည်”** ဟု သုံးမည်။ ဖုန်း checkout ကို မလိုအပ်ဘဲ scroll မလုပ်ရအောင် စာနဲ့အဆင့်တွေ ချုံ့မည်။ Login ပုံစံကို ဆက်ထိန်းမည်။
- အော်ဒါ record သိမ်းပြီးလျှင် **Telegram တန်းဖွင့်မည်**။ Website မှာ **“အော်ဒါတင်ပြီးပါပြီ”**၊ အော်ဒါအမှတ်၊ Telegram ပြန်ဖွင့်ရန်နဲ့ စာကူးယူရန်ကို ဆက်ပြမည်။ ဒါက ငွေပေးချေပြီး/ဆိုင်အတည်ပြုပြီးဟု မဆိုလိုပါ။
- သက်တမ်းကျန်တာကို **ကျန်ရက်ကြီးနဲ့ စက်ဝိုင်း countdown** ဖြင့် ပိုသိသာအောင် ပြမည်။ Pending/ဝယ်ယူပြီး နှစ်မျိုး ကြည့်နိုင်မည်။
- **KBZPay၊ Wave၊ AYA Pay၊ UABpay၊ Binance** logo များကို အပေါ်နားနဲ့ checkout မှာ အတိုချုံးပြမည်။ ငွေပေးချေမှုကို Telegram မှာ ဆက်လုပ်ရကြောင်း ရှင်းပြမည်။

## နောက်လုပ်ရန် ၄ ခု

1. ပြင်ထားသော wireframe ကို စစ်ပြီးမှ website UI ကို ဆက်ပြင်ရန်။
2. မြန်မာခလုတ်စာသား၊ ဖတ်ရလွယ်မှုနဲ့ password အကူအညီကို ဦးစားပေးရန်။
3. သီးခြား test environment မှာ Telegram မပွင့်ခြင်း၊ reload နှင့် guest order ပြန်ရယူမှုကို စမ်းရန်။ ဒီ recovery ကို live မှာ အတည်မပြုရသေးပါ။
4. တကယ့်ဖုန်းတွေနဲ့ လူကြီးပိုင်း ၅–၇ ဦးကို စမ်းပြီး မှားနှိပ်မှုနဲ့ နားမလည်သောအဆင့်တွေကို ထပ်ပြင်ရန်။
