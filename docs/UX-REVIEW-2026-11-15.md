# Account / Giveaway UI–UX စမ်းသပ်ချက်

ဒီစစ်ဆေးမှုက browser နဲ့ disposable data သုံးထားတဲ့ functional/visual review ဖြစ်ပါတယ်။ လူကြီးပိုင်း participant တွေကို ခေါ်စမ်းထားတဲ့ study မဟုတ်ပါ။

| စစ်ဆေးချက် | ရလဒ် |
| --- | --- |
| Phone 320 / 390px၊ desktop 1440px | ဘေးလျှံမှု မရှိ။ Desktop customer content က screen 80% သုံးသည် |
| Account brief | Plan logo၊ segmented အဝိုက်၊ ရက်ကျန်နဲ့ date ခွဲထားသည်။ Gear ခလုတ် 44px |
| Full Account | Profile / sign-in methods / linking / password settings သာပြသည်။ History မပြ |
| Full History | Desktop နှစ်ကော်လံ။ Meter ကို ဘယ်ဘက်စီထားပြီး အလယ်နေရာလွတ်ကြီး မရှိ။ Phone တစ်ကော်လံ |
| Day states | 365 / 23 / 3 ရက်၊ ends today၊ upcoming၊ expired ကိုစစ်ပြီး။ Percentage မပြ |
| Account / History က ပြန်ထွက်ခြင်း၊ reload | Receipt အဟောင်း မပွင့်တော့။ Cart → View saved order နဲ့သာ ပြန်ဖွင့်နိုင် |
| Admin account fields | လေးခုလုံး optional။ Fake values သိမ်းပြီး ဝယ်ထားသူ history မှာ ပြနိုင်။ Password ကို reveal/hide လုပ်နိုင် |
| Telegram linking | Illustrated guide၊ code ပြခြင်း၊ cancel နဲ့ mocked bot approval → Connected အထိ စစ်ပြီး။ ယခင် customer/order ပိုင်ဆိုင်မှု မပြောင်း |
| Giveaway | Draft preview၊ MMT ရက်သတ်မှတ်/Save/Launch ကို local မှာစစ်ပြီး။ မချိတ်ရသေးသူကို guide ပြ၊ ချိတ်ပြီးသူ join → Admin Entries 1 ဖြစ်သည် |
| Privacy / Accessibility | Full Account/History မှာ storefront analytics မရှိ။ Keyboard focus၊ meter day ARIA values၊ forced-colors နဲ့ reduced-motion စစ်ပြီး |

Giveaway ကို local fixture မှာသာ Launch/Join လုပ်ထားပါသည်။ Live မှာ draft အဖြစ်ထားပြီး owner က ရက်သတ်မှတ်၊ Launch နှိပ်ရပါမည်။ Actual Telegram app ကို မဖွင့်ပါ။
